# 架空案件インプット: 「鎌倉工芸社」コーポレートサイトリニューアル

> これは複数プラグイン横断検証用の **架空案件**（フィクション）。実在の企業ではない。
> `/req-collect` 系の requirements-extraction スキルに渡すクライアント要件説明テキストの想定。

## 案件概要

100 年続く老舗工芸メーカー「鎌倉工芸社」のコーポレートサイトを全面リニューアルする。BtoB の取引先（百貨店・ホテル・寺社）と、BtoC の見学希望者・採用希望者・メディア取材の窓口になる。**会員機能や決済は不要**。製品カタログと事業内容、ブランドストーリーを伝えるサイト。

Web のみ。スマホ・PC ともに対応。**速さ・SEO・ブランド体験**が要件の中核。

## 想定ユーザー

- **取引先担当**: 既存・新規。製品カタログを見て問い合わせ
- **エンドユーザー（消費者）**: ブランドストーリー・職人紹介・店舗一覧を閲覧
- **採用候補者**: 採用情報・職人インタビューを閲覧
- **メディア記者**: プレスリリース・取材問い合わせ
- **広報担当（社内）**: コンテンツ更新

## 機能まわりの要望（ヒアリング結果）

### 認証
- **エンドユーザー向け会員機能は不要**。問い合わせフォームだけで OK
- 広報担当（社内）の CMS ログインのみメール + PW + IP 制限
- 社外向けの認証は無し

### コンテンツ管理
- 製品カタログ（カテゴリ × 商品、写真複数枚 + スペック表）
- ブランドストーリー（記事形式、年表、職人インタビュー）
- 店舗・取扱店一覧（地図表示）
- 採用情報（職種別、職人インタビューと連動）
- プレスリリース・お知らせ（公開日時管理）
- ヘッドレス CMS（microCMS or Contentful）を想定。**Markdown + 画像複数**の編集体験を確保

### 問い合わせフォーム
- 取引先用 / 一般用 / 採用用 / メディア用の 4 種類
- 添付ファイル可（取引先・メディア）
- スパム対策（reCAPTCHA）
- 受信後の確認メール自動送信 + 担当部署への振り分け通知

### 静的サイト・OGP
- ページ表示は全 SSG（静的生成）を基本にしたい
- 製品ページ・記事ページごとに OGP 画像を**事前生成**（タイトル + 製品写真合成）
- 構造化データ（Organization / Product / NewsArticle）対応
- 多言語対応は将来。MVP は日本語のみ

### 計測
- Google Analytics 4
- 問い合わせフォームのコンバージョン追跡
- ヒートマップは Microsoft Clarity 程度で可

## 非機能・制約

- 表示速度: PageSpeed Insights モバイル 90 点以上を目標
- バックエンドは最小限。Next.js + ヘッドレス CMS のような構成想定
- ホスティング: Vercel / Cloudflare Pages 想定
- バリアフリー（WCAG 2.1 AA 相当）に配慮
- アクセス数: 月間 30 万 PV 程度の見込み
- 個人情報は問い合わせフォームのみ。**個人情報の長期保存はしない**

## 体制・スケジュール

- クライアント: 広報部長 + 広報担当 1 名
- 開発: FE 2 / デザイン 1 / PM 1
- 目標: 4 ヶ月でリニューアル公開
