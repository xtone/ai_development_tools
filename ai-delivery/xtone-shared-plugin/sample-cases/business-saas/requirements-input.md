# 架空案件インプット: 「打刻ノート」中小企業向け勤怠管理 SaaS

> これは複数プラグイン横断検証用の **架空案件**（フィクション）。実在のサービスではない。
> `/req-collect` 系の requirements-extraction スキルに渡すクライアント要件説明テキストの想定。

## 案件概要

社員 10〜100 名規模の中小企業向け勤怠管理 SaaS「打刻ノート」を新規開発する。既存の大手勤怠 SaaS は機能が多すぎて使いこなせない層をターゲットに、**ぱっと打刻 → 月末に承認 → 給与 CSV 連携**だけを軽量に提供する。

Web（PC・スマホブラウザ）が中心。スマホアプリは出さない方針（PWA で対応）。

## 想定ユーザー

- **従業員**: 打刻 / 休暇申請 / 自分の勤務記録閲覧
- **承認者（管理職）**: 部下の勤怠承認・修正
- **経理担当**: 月次締め・給与 CSV エクスポート
- **管理者（システム管理者）**: 会社設定・社員マスタ・権限・連携設定
- **テナント運用（自社）**: マルチテナント運用、契約管理、サポート対応

## 機能まわりの要望（ヒアリング結果）

### 認証
- メール + PW を基本に、**SAML / OIDC でクライアント側 IdP（Google Workspace / Microsoft Entra ID）と SSO 連携**
- 管理者は MFA 必須、一般従業員は任意
- パスワードレス（メールマジックリンク）も検討

### マルチテナント
- 1 アカウント = 1 社（テナント）
- 同じメールアドレスで複数テナントに所属できる（兼業対応）
- テナント間データ完全分離（DB 行レベルでテナント ID 必須）

### 勤怠機能
- 打刻（出勤 / 退勤 / 休憩開始 / 終了）。**ボタン 1 タップで完了**
- 打刻忘れの事後修正（承認フロー）
- 休暇申請・残数管理（有給 / 振休 / 特別休暇）
- シフト勤務・フレックス・裁量労働の 3 形態
- 残業時間の自動計算と 36 協定アラート
- 法定休日 / 法定外休日の判別

### 管理画面
- 経理向け月次締め画面
- 管理者向け社員マスタ・組織図・権限管理
- **RBAC**: 従業員 / 承認者 / 経理 / 管理者 / 自社サポート（テナント横断閲覧）
- 組織図に基づく承認ルート自動構築

### 連携
- 給与 CSV エクスポート（マネーフォワード給与 / freee 人事労務 / 弥生給与の形式）
- カレンダー連携（Google / Outlook）で休暇予定を同期
- Slack 通知（打刻リマインド・承認待ち）

### 通知
- 打刻忘れリマインド（毎日定時 + 月末）
- 承認待ちアラート → 承認者へ
- 36 協定超過アラート → 本人 + 管理者

### 監査ログ
- 勤怠データの編集・削除・承認は全件ログ
- 監査ログは**3 年保管**、改ざん不可
- 監査ログ閲覧は管理者と自社サポートのみ

## 非機能・制約

- 同時アクセス: 1 テナント最大 100 名 × 数百テナント
- 月初・月末ピークで応答 1 秒以内
- バックエンドは Rails、フロントは React 想定
- 個人情報は給与情報を含むため厳格管理
- 国内クラウド（AWS 東京）、海外リージョン不可
- 監査・帳票出力に**ログ保管 3 年・データ保管 7 年**を求める法的要件あり

## 体制・スケジュール

- クライアント: 自社サービス（受託ではなく自社 SaaS 立ち上げ）
- 開発: BE 2 / FE 2 / インフラ 1 / PM 1 / セールス兼 CS 1
- 目標: 8 ヶ月で β 公開、12 ヶ月で正式版
