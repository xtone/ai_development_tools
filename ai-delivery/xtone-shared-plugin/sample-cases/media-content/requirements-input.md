# 架空案件インプット: 「日々（hibi）」ライフスタイルメディア

> これは複数プラグイン横断検証用の **架空案件**（フィクション）。実在の媒体ではない。
> `/req-collect` 系の requirements-extraction スキルに渡すクライアント要件説明テキストの想定。

## 案件概要

老舗ライフスタイル雑誌「日々（hibi）」のデジタル版をリニューアル。記事数は約 12,000 本のアーカイブを持ち、毎月 80〜100 本の新規記事を追加する編集体制。SEO 流入と読者会員（無料 + 有料）の両軸で収益化する。

Web（PC・スマホブラウザ）が主戦場。スマホアプリは出さない方針。OGP・SEO・パフォーマンス最優先。

## 想定ユーザー

- **匿名読者**: SNS 流入・検索流入が大半。OGP がきれいに出ることが必須
- **無料会員**: お気に入り保存・コメント・著者フォロー・ニュースレター購読
- **有料会員**: 過去アーカイブ全文閲覧・特集記事の完全版・限定オンラインイベント参加
- **編集者**: 記事執筆・編集・公開予約・特集編成
- **広告営業**: スポンサード記事の出稿・タグ管理

## 機能まわりの要望（ヒアリング結果）

### 認証
- 無料会員はメール + PW、または Google ログイン
- 有料会員は決済情報と紐付け（決済は別 SaaS でやるので連携のみ）
- 編集者・広告営業は社内 SSO（Google Workspace）必須
- ソーシャルログインを後から有料アカウントに紐付けたい

### コンテンツ管理
- 編集者向け CMS。Markdown ベース + リッチエディタを併用
- 記事メタ（カテゴリ、タグ、著者、公開日時、有料/無料フラグ、関連記事）
- **特集**は記事を束ねる単位。トップに大型ビジュアル + 編集者ことばを置く
- 公開予約・下書き共有・差し戻し
- 過去記事の修正履歴と差分閲覧

### 検索
- フリーワード検索（記事本文 + メタ）
- 絞り込み: 著者・カテゴリ・タグ・期間・有料/無料
- **おすすめ・関連記事**は編集者が手で選べる + 自動推薦の併用
- サイト内検索は OS 内蔵検索（SaaS 利用可、Algolia / Meilisearch 想定）

### 広告・計測
- 記事内に **PR 表記**を強制したスポンサード枠
- ディスプレイ広告は GAM（Google Ad Manager）想定
- 記事単位の閲覧時間 / スクロール深度 / 読了率を計測
- 計測は Google Analytics 4 + 自社ログ DB（BigQuery）への日次連携

### OGP・SEO
- 記事・特集・著者ページごとに **OGP 画像を自動生成**（タイトル + サムネ合成）
- 構造化データ（schema.org Article / NewsArticle）
- サイトマップは特集・著者・タグページも含めて自動生成
- AMP は廃止予定なので不要

## 非機能・制約

- 同時アクセス 1 万 PV/分の特集公開時にも 1 秒以内の応答
- 検索 → 結果表示は 500ms 以内
- バックエンドは Rails / Next.js のどちらでも可。**JAMstack 寄りの構成（静的化 + Incremental Static Regeneration）を検討してほしい**
- 過去 12,000 本のアーカイブ移行が必須。旧 CMS から JSON エクスポート可
- 個人情報は決済情報を含むため、ログイン会員情報は厳格管理（個人情報保護法準拠）

## 体制・スケジュール

- クライアント: 編集長 + デジタル担当 1 名 + 広告営業 1 名
- 開発: BE 1 / FE 2 / インフラ 1 / デザイン 1 / PM 1
- 目標: 6 ヶ月で公開
