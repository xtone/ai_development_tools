# image-preview

Claude Code のプロンプトに添付した画像をプレビューする mod です。

- **送信前**：画像を添付すると、入力欄のすぐ上にサムネイルが出ます（Cmd+V での貼り付け・D&D のどちらも）。
- **送信後**：送った画像を右側のペインに大きく表示します。
- 画像の下には元ファイルのパスと、「Finder で表示」「パスをコピー」のボタンが付きます。
- 入力欄から `[Image #N]` を消すと、その画像はプレビューから外れます。

## コマンド

| コマンド | 動作 |
| --- | --- |
| `/image-preview` | プレビューのペインを開く |
| `/image-preview clear` | プレビューと一時ファイルを消す |

## 動作環境

| 項目 | 条件 |
| --- | --- |
| Claude Code | mod（関数フック）に対応した版。2.1.310 / 2.1.311 で動作確認 |
| OS | **macOS のみ**（`sips`・`osascript`・`open -R`・macOS の `base64 -D` を使う） |
| 画面 | ターミナル版の Claude Code（デスクトップアプリ・VS Code 拡張では画像が出ません） |
| ターミナル | 画像を描けるもの：**Ghostty・kitty** で表示。iTerm2 は 3.5 以降でも、ファイルから読む方式のため表示できない場合があります。tmux の中では表示されません。描けないターミナルでは、画像の代わりに `[Image #N]` などの文字が出ます |
| ペインの幅 | 送信後のペインは、自動で開くとき端末が 144 列以上必要です。狭いときは `/image-preview` で開けます |

## 仕組みと注意

- 送信前の添付画像は Claude Code から mod に渡されないため、次の方法で画像を手に入れています。
  - D&D：macOS のドラッグ用ペーストボードから、直前にドラッグしたファイルのパスを読む
  - Cmd+V：貼り付けた瞬間のクリップボードの画像（Finder でコピーしたファイルならそのパス）を読む
- そのため、貼り付けたあと送信前に別のものをコピーすると、送信前のプレビューがずれることがあります。送信後のプレビューは、実際に送った画像から作るのでずれません。
- 入力欄を 0.4 秒ごとに確認して、添付をすぐ検出します。
- 変換した PNG は mod のフォルダの `.cache/` に、動作の記録は `debug.log` に置きます。

## 入れ方

```
/plugin marketplace add xtone/ai_development_tools
/plugin install image-preview@xtone-ai-development-tools
/reload-plugins
```

フォルダを直接読み込む場合は `claude --plugin-dir <このフォルダ>` で起動します。
