# Review Feedback Learner

PRレビューで受けた指摘をCLAUDE.mdのルールとして蓄積する Claude Code スキルです。

**Version**: v1.1

---

## 背景

Boris Cherny氏のTip #3「CLAUDE.mdへの投資」の拡張版です。
PRレビューで繰り返し指摘されるパターンをルール化し、同じ指摘を受けないコードベースを実現します。

> 「レビュアーの暗黙知をチーム全体の資産に」

---

## lessons-md-managerとの補完関係

| スキル | 学びの源泉 | タイミング |
|--------|-----------|-----------|
| `/lessons` | 自分で気づいた失敗・修正 | セッション終了時 |
| `/review-learn` | 他者からの指摘 | PRマージ後 |

両方使うことで、**個人の気づき＋チームの知見**が蓄積されます。

---

## 機能

- **対応済みフィルタリング**: 対応した指摘のみを蓄積し、未対応のノイズを自動除外
- **Bot/人間の自動分類**: `[bot]` 判定で Bot コメントをデフォルト除外（対応済みなら昇格）
- **GraphQL データ取得**: `isResolved` / `isOutdated` を活用した高精度な対応済み判定
- **APPROVED body 解析**: APPROVED レビューの body から個別の指摘を抽出
- **確度別グループ表示**: 確実/おそらく対応した指摘を分けて提示
- **レビューコメント取得**: GitHub CLI でPRのレビューコメントを自動取得
- **カテゴリ分類**: 命名規則/アーキテクチャ/エラーハンドリング等に自動分類
- **ルール化**: 繰り返し適用できるパターンを抽出
- **重複チェック**: 既存ルールとの重複を検出
- **クレジット付与**: 指摘者のGitHubアカウントとPR番号を記録
- **PF非依存**: あらゆるGitHubリポジトリで使用可能

## インストール

### Claude Code での使用

1. このスキルをプロジェクトにコピー:
   ```bash
   cp -r review-feedback-learner /path/to/your-project/.claude/skills/
   ```

2. またはパーソナルスキルディレクトリにリンク:
   ```bash
   ln -s /path/to/review-feedback-learner ~/.claude/skills/review-feedback-learner
   ```

3. Claude Code を再起動（既に実行中の場合）

### 前提条件

- GitHub CLI (`gh`) がインストール済み
- `gh auth login` で認証済み

## 使い方

### 直近のマージ済みPRから学ぶ

```
/review-learn
```

直近5件のマージ済みPRを表示し、選択したPRのレビューコメントからルールを抽出します。

### 特定のPRから学ぶ

```
/review-learn #123
```

指定したPR番号のレビューコメントからルールを抽出します。

### 自分のPR全体から学ぶ

```
/review-learn --my-prs
```

自分が作成したマージ済みPR（直近5件）のレビューコメントをまとめて分析します。

## 出力フォーマット

CLAUDE.mdに追記される形式:

```markdown
## Review Learnings

このセクションはPRレビューで受けた指摘から自動生成されました。

### 命名規則
- Repository層のメソッドは `fetchXxx` ではなく `getXxx` を使う
  - 📝 PR #123 で @tanaka さんが指摘

### エラーハンドリング
- API呼び出しでは `Result<T, E>` でラップし、呼び出し元で処理する
  - 📝 PR #120 で @suzuki さんが指摘

### アーキテクチャ
- ViewModelからRepositoryを直接参照しない。UseCase経由でアクセスする
  - 📝 PR #118 で @yamamoto さんが指摘
```

## カテゴリ一覧

| カテゴリ | 内容 |
|---------|------|

## 複数人リポジトリでの価値

| シナリオ | 効果 |
|----------|------|
| **新メンバー参加** | 過去のレビュー指摘が蓄積済み。同じミスをしない |
| **レビュアー** | 同じ指摘を繰り返す手間が減る |
| **チーム全体** | 暗黙知が形式知化され、コード品質が均一に |
| **オンボーディング** | 「なぜこのルール？」の背景（PR番号）が追跡可能 |
