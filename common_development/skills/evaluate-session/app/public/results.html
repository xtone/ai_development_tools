    Session Evaluator - Help

    Session Evaluator とは？

    Claude Code のセッション（JSONL）を解析し、ツール使用効率・トークン消費・手戻りなどを可視化するツールです。
    AIによる 7 観点のスコアリング評価（100 点満点）も実行できます。

    基本的な使い方

    1
    Sessions ボタンで一覧画面へ戻り、Projects から対象プロジェクトを選択します。~/.claude/projects 配下のプロジェクトが自動で一覧されます。
    2
    一覧画面の Sessions テーブルで分析対象セッションを選択し、Analyze または Stats Only でこの結果画面へ遷移します。
    3
    ツールバーのボタンで分析を実行します：
    • ▶ Analyze — Claude による AI 評価 + 統計レポートを生成（1分ほどかかります）
    • Stats Only — 統計レポートのみ生成（高速、Claude 呼び出しなし）
    4
    結果はこのページの Visual / Plain Text タブに表示されます。

    その他のボタン

    • Open Session... — フォルダ選択ダイアログから任意のセッションフォルダを直接開きます
    • Copy Result — 現在の結果をクリップボードにコピーします
    • History — 過去の評価履歴を確認し、Visual タブに復元できます
    • Model ドロップダウン — AI 評価に使用する Claude モデルを選択します（sonnet / opus / haiku）

    評価の 7 観点（100 点満点）

    「品質」ではなく「無駄の有無」を評価します。平均的なセッションは 50〜65 点が目安です。

    • A. 重複作業（/15） — 同一ファイル重複 Read、同じファイルの複数回書き直し、サブエージェントとの作業重複
    • B. トークン効率（/15） — 入力トークンの異常値、キャッシュ活用率、大型ツール結果によるコンテキスト肥大
    • C. 目的外作業（/20） — ユーザー指示と無関係なファイル操作、頼まれていないリファクタリング（最重要観点）
    • D. 初動の的確さ（/15） — タスクに適した初手を取れているか、不要な前置き作業がないか
    • E. エラー回復効率（/10） — エラー後に原因分析せず同じことをリトライしていないか
    • F. 不要な探索（/15） — 目的に不要なファイル読み込み、過剰な Glob/Grep
    • G. モデル選定（/10） — タスク複雑さに対してモデルが適切か、サブエージェントのモデル選定

    スコアの目安

    • 80〜100 — 極めて効率的（ほぼ無駄なし）
    • 65〜79 — 良好（軽微な無駄のみ）
    • 50〜64 — 平均的（改善の余地あり）
    • 30〜49 — 非効率（明確な無駄が複数）
    • 0〜29 — 大幅な改善が必要

    Visual タブの見方

    • スコアカード — 合計スコアとカテゴリ別スコア（緑=良好、黄=普通、赤=要改善）
    • Tool Usage — ツールごとの使用回数を横棒グラフで表示
    • Duplicate Reads — 同一ファイルを複数回読み込んだ箇所
    • Rework — 同一ファイルへの書き込みが3回以上あった箇所（手戻り）
    • Errors & Retries — エラー発生数と即座のリトライ数
    • Planning — セッション最初の15ツール呼び出し（調査系=緑、その他=青）

    トラブルシューティング

    • Claude CLI が見つからない — claude --version でインストール確認。Stats Only なら CLI 不要で利用可能
    • ポートが使用中 — npx session-evaluator --port 8080 で別ポートを指定
    • セッションが表示されない — ~/.claude/projects/ にログが存在するか確認
    • 評価が途中で失敗 — Claude CLI の認証やネットワーク接続を確認。Stats Only で統計だけ確認可能

    CLI から起動する場合

    npx session-evaluator でサーバーが起動し、ブラウザが自動で開きます。--port でポート変更可。
