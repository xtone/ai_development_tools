# Claude Code スキルレビュー

Claude Codeスキルの品質を公式ベストプラクティスに基づいてレビューするスキルです。

## いつ利用するか

- PRにSKILL.mdファイルが含まれている場合
- スキルの品質チェックを依頼された場合
- 新しいスキルを作成する際の自己レビュー

## 公式ドキュメント参照

詳細なルールと背景については以下を参照してください：

- **スキル概要**: @references/01_skill_overview.md
- **ベストプラクティス**: @references/02_best_practices.md

## レビュー手順

### ステップ1: フロントマター検証（Critical）

| フィールド | 要件 |
|-----------|------|
| `name` | 必須、最大64文字、小文字・数字・ハイフンのみ、予約語（anthropic, claude）なし |
| `description` | 必須、空でない、最大1024文字 |

**Critical判定**:
- フロントマターが欠落 → Critical
- `name`が不正な形式 → Critical
- `description`が空 → Critical

### ステップ2: description品質チェック（Major/Minor）

**必須要素（Major）**:
1. **何をするか**: スキルの機能を具体的に説明
2. **いつ使用するか**: トリガー条件を明記

**品質チェック（Minor）**:
- ✅ 三人称で記述（「〜します」「〜を処理する」）
- ✅ 具体的なキーワードが含まれている
- ❌ 一人称・二人称は避ける（「お手伝いします」）
- ❌ 曖昧な表現は避ける（「ドキュメントに役立ちます」）

### ステップ3: ディレクトリ構造チェック（Critical/Major）

**マーケットプレイス配布用の正しい配置**:
```
{domain}/skills/{skill-name}/
├── SKILL.md           # 必須
├── references/        # オプション
└── scripts/           # オプション
```

**Critical: 誤った配置**:
- ❌ `~/.claude/skills/` - ユーザーのインストール先
- ❌ `.claude/skills/` - プロジェクト固有スキル用

**Major: 命名規則違反**:
- ❌ CamelCaseやsnake_case
- ✅ kebab-case（動名詞形を推奨: `processing-pdfs`）

### ステップ4: SKILL.mdボディ品質チェック（Minor）

- ✅ 500行以下（超える場合は別ファイルに分割）
- ✅ 具体的な例（Example）が含まれている
- ✅ 明確なワークフロー/ステップがある
- ✅ 全体で一貫した用語が使用されている
- ✅ Claudeが既に知っている一般知識は省略

### ステップ5: 参照ファイルチェック（Major/Minor）

- ✅ 参照されるファイルがすべて存在する（Major）
- ✅ 参照は1レベル深さまで（Minor）
- ✅ 100行以上のファイルには目次がある（Minor）
- ✅ ファイルパスはフォワードスラッシュ使用（Minor）

### ステップ6: 避けるべきパターン検出

| パターン | 重要度 |
|---------|--------|
| 時間に敏感な情報（「2025年8月以降は〜」） | Major |
| 多くの選択肢を並列提示 | Minor |
| プロンプトインジェクションの脆弱性 | Critical |
| 深くネストされた参照（2レベル以上） | Minor |
| Windowsスタイルのパス（バックスラッシュ） | Minor |

## スコアリング基準

| スコア | 基準 |
|--------|------|
| 10/10 | すべてのチェック項目をクリア |
| 8-9/10 | Minor問題が1-2件 |
| 6-7/10 | Major問題が1件、またはMinor問題が3件以上 |
| 5以下/10 | Critical問題あり、またはMajor問題が複数 |

## 出力フォーマット

```markdown
## 📦 Skill Quality: X/10

### フロントマター
- [✅/❌] name: [評価コメント]
- [✅/❌] description: [評価コメント]

### ディレクトリ構造
- [✅/❌] 配置: [評価コメント]
- [✅/❌] 命名: [評価コメント]

### SKILL.mdボディ
- [✅/❌] 行数: [X行]
- [✅/❌] 例の有無: [評価コメント]
- [✅/❌] ワークフロー: [評価コメント]

### 参照ファイル
- [✅/❌] 存在確認: [評価コメント]
- [✅/❌] ネスト深度: [評価コメント]

### 検出された問題
| 重要度 | 問題 | 推奨される対応 |
|--------|------|---------------|
| [Critical/Major/Minor] | [問題の説明] | [対応方法] |
```
